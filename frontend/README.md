# AI Sana Challenge Hub — frontend

Рабочий интерфейс для бизнеса и студенческих команд. Ветка `frontend-interface`, изменения только в `frontend/`. Контракт API соответствует `../docs/api-contract.md`.

## Запуск

Node.js 22.12+ (или 24 LTS).

```sh
cd frontend
npm ci
cp .env.example .env.local
npm run dev
```

В Windows вместо `cp` используйте `copy`. Откройте http://localhost:5173.

`VITE_USE_MOCKS=true` включает отдельное демонстрационное хранилище в браузере. Деморежим явно подписан; реальный AI не вызывается. Доступны конструктор, подтверждение/отклонение и редактирование полей, рейтинг с расшифровкой, история, достижения, публикация, каталог с фильтрами, рекомендации, отклики, ручное решение бизнеса, этапы, лидерборд, AI Inspector и сброс демо с подтверждением.

## Подключение backend

1. Получите актуальные изменения `main`, когда участник A опубликует backend.
2. Запустите backend на порту 8000 по инструкции участника A.
3. В `frontend/.env.local` установите `VITE_USE_MOCKS=false`.
4. Выполните `npm run gen:api` при работающем backend. Генерация создаёт `src/api/schema.d.ts`; написанные по контракту DTO находятся в `src/api/types.ts`. Сверьте их с полученной схемой при интеграции.
5. Перезапустите frontend и пройдите сценарий `../docs/demo-script.md`.

Все запросы браузера используют `/api`; Vite перенаправляет их на localhost:8000. Если backend работает на другом компьютере, задайте переменную окружения процесса `API_PROXY_TARGET=http://<адрес>:8000`. Никакие ключи AI во frontend не нужны.

## Проверки

```sh
npm run build
npm run typecheck
npm run lint
npm test
npm run test:e2e
```

E2E рассчитаны на чистое демохранилище и установленный Google Chrome. В ограниченной среде Codex запуск отдельного Chrome может блокироваться ОС; тогда сценарий проверяется через встроенный браузер. Четыре модульные проверки покрывают начисление баллов, золотой пример 27 → 76 → 96 → 100, сохранение подтверждённых полей и однократность начисления баллов этапа.

Ручная браузерная проверка: создание → ответы → подтверждение и правки → публикация на 100 баллах → рекомендации → отклик Nomad AI → выбор бизнесом → этап → 10 баллов в лидерборде → перезагрузка. Проверены фильтры, пустая выдача и узкий экран; ошибок браузерной консоли не обнаружено.

Важная деталь демо: после подтверждения первоначальной потребности AI не имеет права менять её. Три ответа доводят рейтинг до 72; чтобы получить 76, вручную дополните поле «Потребность» до конкретного описания от 60 символов. ## Ограничения текущего этапа

Backend отсутствовал в `origin/main` при реализации. Реальная интеграция и генерация OpenAPI ещё не проверены. Model Lab и лидерборд заказчиков (P2) не реализованы. Деморекомендации — имитация по темам, не эмбеддинги и не TF-IDF. Для записи финального демо нужен прогон с backend участника A.
