# ТЗ для B: полировка интерфейса — темы, языки, анимации, качество

Цель: интерфейс, за который не стыдно на защите. Приятный, единый по стилю, с аккуратными анимациями, светлой и тёмной темой, тремя языками и без единого бага на демо. Функциональность уже работает на настоящем API и проверена e2e-тестами. Задача — довести вид и поведение, ничего не сломав.

## 0. Жёсткие ограничения (нарушать нельзя)

1. Работать только в `frontend/`. Backend, API-контракт и `docs/` (кроме `frontend/README.md` и `docs/screenshots/`) не трогать.
2. Все 8 шагов сценария из `docs/demo-script.md` продолжают работать. Бизнес-логику и запросы к API не менять.
3. Оба e2e-теста проходят: `tests/e2e/demo.spec.ts` (моки) и `tests/e2e/real-api.spec.ts` (настоящий API). Они опираются на следующее, это сохраняем:
   - **CSS-классы и id:** `.score-ring strong`, `.field-card`, `#field-<key>`, `#q1`…`#qN`, `.my-task-row`, `.leader-row`, `.leader-points`, `.task-tile`.
   - **Кнопки:** «Попробовать пример», «Проанализировать», «Подтвердить всё», «Собрать карточку», «Сохранить», «Опубликовать задачу», «Опубликовать», «Бизнес», «Команда», «Отправить отклик», «Выбрать», «Добавить», «Подтвердить», «Как это работает», «Промпты и схемы», «Приоритетная», «Все уровни», «Сбросить фильтры».
   - **Ссылки:** «Рекомендации», «Лидерборд», «Отклики…».
   - **Подписи полей:** «Тема задачи», «Я проверил карточку», «Идея · от 20 символов», «План · от 20 символов», «Срок», «Название этапа», «Поиск задач».
   - **Заголовки и тексты:** «Уточним самое важное», «Сделаем задачу понятной», «Задача опубликована!», «AI Inspector», «Задачи не найдены», «Рекомендации не ограничивают каталог.», «Отклик отправлен.», «Выбрана», «Подтверждён».
   - На странице 0 ошибок JS. При ширине 390 px нет горизонтального скролла.
   Если текст или разметку нужно изменить, обнови оба теста в том же коммите.
4. **Язык по умолчанию — всегда русский.** По языку браузера не определять: Playwright запускается с `en-US`, и тесты упадут.
5. Новых тяжёлых зависимостей не добавлять. Уже есть `motion`, `canvas-confetti`, `sonner`, `radix-ui`, `lucide-react`, `recharts`, `@tanstack/react-query`, Tailwind v4. Переводы делаем без библиотеки (раздел 3).
6. `VITE_USE_MOCKS=false` по умолчанию. Никаких ключей и секретов во frontend.
7. Коммитить со своего GitHub-аккаунта маленькими коммитами: это твой личный вклад, его требуют правила.

## 1. Визуальная система

- **Токены.** Все цвета, радиусы, тени и отступы — CSS-переменные в одном месте: `:root` и `[data-theme="dark"]` в `src/index.css`. В компонентах и CSS-классах никаких захардкоженных hex-цветов.
- **Набор токенов:** фон, поверхность, поверхность-2, граница, текст, приглушённый текст, акцент (фирменный `--green`), акцент при наведении, успех, предупреждение, ошибка, инфо.
- **Цвета уровней:** Черновик — slate, Рабочая — sky, Готовая — emerald, Приоритетная — amber со свечением. **Статусы полей:** пусто — приглушённый, «Предложено AI» — violet, «Подтверждено» — emerald.
- **Типографика:** одна шкала размеров (12/14/16/20/24/32/40), единые веса и межстрочные интервалы. У баллов, счётчиков и мест в рейтинге — `font-variant-numeric: tabular-nums`.
- **Отступы:** шкала 4/8/12/16/24/32/48, одинаковые внутренние отступы у всех карточек. Сетка каталога — 3, 2 или 1 колонка в зависимости от ширины.
- Единые радиусы и тени у карточек, кнопок, полей ввода и модалок. Иконки только lucide, один размер на контекст.
- **Фокус:** видимый `:focus-visible` в цвет акцента на всех интерактивных элементах.
- **Контраст** не ниже WCAG AA (4.5:1) в обеих темах.

## 2. Темы: светлая, тёмная, системная

- Переключатель в шапке: иконки солнце, луна, монитор, выбор через меню.
- Выбор хранится в `localStorage` (`theme`), по умолчанию `system`. Смена системной темы подхватывается на лету.
- **Без вспышки при загрузке:** маленький inline-скрипт в `index.html` выставляет `data-theme` на `<html>` до рендера React.
- В тёмной теме проверить всё:
  - графики Recharts (цвета из переменных);
  - JSON в AI Inspector;
  - тосты sonner (проп `theme`);
  - модалки, поповеры, скелетоны;
  - бейджи уровней, кольцо рейтинга, конфетти.
- Плавная смена цветов 150–200 мс при переключении. При загрузке страницы без перехода.

## 3. Языки: русский (по умолчанию), қазақша, English

- **Свой лёгкий i18n.** `src/i18n/ru.ts` — источник ключей (`as const`). `kk.ts` и `en.ts` типизированы от него: пропущенный ключ — ошибка TypeScript. Плюс `I18nProvider`, хук `useT()` и fallback на русский.
- Переключатель RU / KZ / EN в шапке. Выбор хранится в `localStorage` (`lang`), `<html lang>` обновляется (`ru`, `kk`, `en`).
- **Переводится весь интерфейс:** навигация, кнопки, подписи, плейсхолдеры, пустые состояния и ошибки, тосты, подсказки, `aria-label`, заголовки вкладки.
- **Справочники с backend приходят по-русски:**
  - из `/api/meta` — поля, критерии, уровни, темы;
  - из рейтинга — `breakdown[].checks[].label`, `missing[].hint`, ачивки.
  Для KZ и EN переводим на frontend по ключам: `field.key`, `criterion`, `level.key`, `topic.key`, `check_id`, `achievement.key`. Нет перевода — показываем текст с сервера.
- **Контент пользователя и AI не переводим:** черновик, вопросы AI, значения карточки, отклики остаются на языке автора.
- Даты и числа форматируем через `Intl` по выбранной локали (`ru-RU`, `kk-KZ`, `en-US`), «2 часа назад» — через `Intl.RelativeTimeFormat`.
- **Казахский:** переводы можно сделать с AI, но прочитать глазами. Буквы ә, ғ, қ, ң, ө, ұ, ү, һ, і должны корректно отображаться выбранным шрифтом.
- Длинные английские и казахские строки не должны ломать кнопки, бейджи и навигацию. Проверить все три языка.

## 4. Анимации (motion): спокойно и со смыслом

- **Смена страниц:** fade и сдвиг на 8 px, 200–250 мс (`AnimatePresence` по ключу маршрута).
- **Списки** (каталог, вопросы, отклики, лидерборд): stagger 30–40 мс, с задержкой анимируются не больше 10 элементов.
- **Кольцо рейтинга** — главный момент демо:
  - плавное заполнение и счётчик числа, 600–800 мс;
  - «+N» всплывает и растворяется;
  - цвет уровня меняется плавно.
- **Новый уровень:** тост «Новый уровень: Готовая». Конфетти только при уровне «Приоритетная» и при 100 баллах: один раз, не дольше 1,5 секунды.
- **Ачивки:** значок «загорается» при получении (scale 0.8→1 и свечение).
- **Поля карточки:** при подтверждении мягкая зелёная подсветка 600 мс, при отклонении аккуратное сворачивание.
- **Кнопки:** при наведении подъём на 1 px и тень, при нажатии scale 0.98. У неактивных кнопок анимаций нет.
- **Загрузка:** скелетоны с shimmer вместо «Загрузка…». Запрос к AI идёт 8–13 секунд, поэтому показываем прогресс из трёх шагов: «Читаем черновик» → «Ищем пробелы» → «Готовим вопросы», смена примерно каждые 3 секунды.
- При `prefers-reduced-motion: reduce` анимации отключаются или становятся мгновенными, конфетти не запускается.
- Никаких анимаций, сдвигающих макет, и никаких бесконечных анимаций, кроме индикатора загрузки.

## 5. Экраны: что довести

- **Шапка:**
  - логотип и навигация;
  - переключатель роли и выбор бизнеса или команды;
  - бейдж AI-провайдера с меню: OpenAI, Brev (приватно), Офлайн, а также «Сбросить демо» с подтверждением;
  - переключатели темы и языка.
  На узких экранах шапка компактная, без переносов строк.
- **Конструктор:**
  - степпер с прогрессом;
  - черновик: счётчик символов и пример;
  - вопросы: карточки с «+N баллов», чипом поля и строкой «зачем»;
  - карточка: 10 полей с понятными статусами «Пусто», «Предложено AI», «Подтверждено». Цитаты-доказательства — в поповере с указанием источника;
  - панель рейтинга закреплена справа (sticky);
  - публикация: модалка с чекбоксом и итогом (место в каталоге, уровень).
- **Панель рейтинга:**
  - кольцо, уровень, «до следующего уровня N», потенциал AI;
  - топ-3 подсказки: по клику плавная прокрутка к полю, фокус и подсветка;
  - расшифровка по 7 критериям (аккордеон), ачивки, мини-график истории.
- **Каталог:**
  - карточки одинаковой высоты; приоритетные с золотой рамкой; черновики приглушены и помечены «Требует уточнения»;
  - фильтры: тема, уровни, поиск с задержкой 300 мс, сортировка. Состояние фильтров хранится в URL (`?topic=&level=&q=&sort=`);
  - счётчик найденных задач; пустое состояние с кнопкой «Сбросить фильтры».
- **Страница задачи:** читаемая карточка, расшифровка рейтинга только для чтения. Форма отклика с проверкой на лету: идея и план от 20 символов, корректный URL. Счётчики символов и понятные ошибки.
- **Рекомендации:** процент совпадения, причины, чипы навыков, подпись «не ограничивают каталог».
- **Мои задачи и отклики:**
  - цветные бейджи статусов;
  - нейтральный чек-лист полноты отклика: без ранжирования и пометок «лучший»;
  - «Выбрать» и «Отклонить», отклонение с подтверждением;
  - этапы: добавление, подтверждение, тост с начисленными баллами.
- **Лидерборд:** медали у мест 1–3, баллы с `tabular-nums`, анимация смены места.
- **AI Inspector:**
  - читаемый JSON с подсветкой, сворачиванием и кнопкой «Скопировать»;
  - цветные статусы вызовов;
  - отклонённые проверкой поля — красным, с причиной;
  - вкладка «Промпты и схемы».
- **Страница 404** и экран «Сервер недоступен» с кнопкой «Повторить».

## 6. «Без приколов»: чек-лист качества

- **Консоль:** на всех экранах в консоли браузера 0 ошибок и 0 предупреждений React (ключи, controlled/uncontrolled).
- **Действия с запросом:**
  - кнопка показывает загрузку и блокируется, двойной отправки нет;
  - ошибка — понятный тост на выбранном языке, можно повторить.
- **Макет:** нет «прыжков» при загрузке данных (фиксированные размеры скелетонов). Длинные тексты переносятся, в карточках каталога обрезаются по строкам (`line-clamp`), полный текст — на странице задачи.
- **Модалки:** фокус внутри (radix), Esc закрывает, фокус возвращается на кнопку.
- **Клавиатура и прокрутка:** всё доступно с Tab в логичном порядке. При переходе на страницу прокрутка вверх, при переходе к полю из подсказки — плавная прокрутка к полю.
- **Адаптив:** основное — 1440 и 1280 px. При 1024 и 390 px нет горизонтального скролла и наложений.
- **Производительность:** бандл разбить по маршрутам (`React.lazy` и `Suspense`; Recharts и confetti — отдельными чанками). Цель: пропало предупреждение Vite о чанке больше 500 kB, в production-сборке на `/catalog` Lighthouse Performance от 90 и Accessibility от 95.
- **Мета:** favicon, заголовок вкладки по странице («Каталог — AI Sana Challenge Hub»), meta description.
- **Тексты:** в русском интерфейсе нет английских остатков, опечаток, «Lorem ipsum» и тестовых строк.

## 7. Как проверять (Definition of Done)

```powershell
git pull origin main                       # или git merge origin/main в свою ветку
cd frontend
npm run typecheck; npm run lint; npm test
npm run build                              # без предупреждения о размере чанка
$env:VITE_USE_MOCKS="true"; npx playwright test tests/e2e/demo.spec.ts
# настоящий API: в другом терминале backend с AI_PROVIDER=stub, затем
$env:VITE_USE_MOCKS="false"; npx playwright test tests/e2e/real-api.spec.ts
```

Ручная проверка — пройти `docs/demo-script.md` в режимах:
- светлая тема и RU;
- тёмная тема и KZ;
- светлая тема и EN;
- с включённым «уменьшением движения» в ОС;
- в окне шириной 390 px.

Скриншоты главных экранов (конструктор, панель рейтинга, каталог, AI Inspector) в светлой и тёмной теме сохранить в `docs/screenshots/`: они пойдут в README.
